# My Activity Tracker

A native Android Activity / Habit Tracker based on the supplied reference video.

## Included
- Today's progress and completion percentage
- Streak tracking
- Date-based activity tracking
- Add / edit / delete habits
- Category and target fields
- Completed / pending states
- Activity filters
- Executive analytics report
- Date-range report
- Print report
- Dark mode
- Local persistent storage
- GitHub Actions APK build

## Build
Use Android Studio or run:

gradle assembleDebug

APK: app/build/outputs/apk/debug/app-debug.apk
